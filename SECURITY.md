# Security policy

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/drbenvincent/tidydraws/security/advisories/new). This repository has private reporting enabled; reports reach the maintainer, @drbenvincent. Include affected versions, a minimal reproducer and the expected impact. Avoid posting exploit details in a public issue.

Security fixes target the latest released version. Older versions may require upgrading. The maintainer reviews Dependabot alerts and automated security-fix PRs; there is no guaranteed response deadline for this volunteer project. Ordinary correctness bugs can use the public bug-report form.
